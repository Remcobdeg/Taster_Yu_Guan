# LSTM ensembles for HAR -- PhD Taster project with Yu Guan, Open Lab

The repository contain code to replicate the algorithm in Guan and Ploetz, ACM 2017, https://doi.org/10.1145/3090076 and explain the code

Specifically, the scripts describe the creation of an ensemble of LSTM models to improve the F2 performance on a benchmark Human Activity dataset (PAMAS)
